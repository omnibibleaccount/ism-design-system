# Imagery
Photography, background gradients and reference creative.

- `deck-photo-*`, `print-photo-*`, `print-cover-*`: real people listening, reading and sharing. Use in heroes, split sections and cards with a dark overlay when text sits on top.
- `photo-friends.jpg`, `photo-listener.jpg`, `photo-phone-street.jpg`: web crops of the matching `print-photo-*` files, with the white print margin removed. Use these in products and components; keep `print-photo-*` for print layouts, where the figure deliberately breaks out of the frame.
- `deck-bg-gradient-dark.jpg`, `deck-bg-gradient-light.jpg`, `deck-bg-faces*.jpg`: section backgrounds.
- `leather-black.jpg`: Bible cover texture for the BibleCard component.
- `ISM-Looks-*`, `Email-*`, `Print-*`, `Social-*`, `Donor-Letter.jpg`, `Dot-Bible-*`: reference creative showing the brand in use. Study them; do not place them in products. They back the guidance in `rules/print-editorial.md`, `email.md` and `social.md`.

Stored with Git LFS (see `.gitattributes`).
