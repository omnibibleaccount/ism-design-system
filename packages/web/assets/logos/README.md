# Logos
ISM and dot.Bible logos. Every file is drawn in **black ink**, including the files named "White" (they were exported without fills and also render black).

- Light surfaces: use the Black files as they are.
- Dark surfaces and photography: use the Black files with `filter: brightness(0) invert(1)`.
- Never recolour, outline, stretch or add effects. See the Logos component for clear space and sizes.
