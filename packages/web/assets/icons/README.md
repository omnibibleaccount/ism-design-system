# Icons
Filled ministry icons (24dp, Material-style), drawn in **black ink**. On dark surfaces render them with `filter: brightness(0) invert(1)`; they do not follow `currentColor`.

- Use for features, stat tiles, steps and outreach content, at 24, 32 or 48px.
- Do not use them inside buttons, fields or navigation. Interface controls use the inline UI line icons (see the Iconography component).
- Decorative: `alt=""`. Pair each icon with a short label.
