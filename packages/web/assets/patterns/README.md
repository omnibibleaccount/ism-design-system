# Patterns
The ISM ring motif and dot textures, drawn in **black ink**.

- `Circle-symbol-1.svg`, `Circle-symbol-2.svg`: rings. Invert on dark and use at 6–20% opacity as background texture.
- `Dots 1–5.png`: dot textures for corners and edges on light surfaces.
- `Pattern1.svg`, `Pattern2.svg`, `Circle-symbol-3.svg`: exported without their styles, so they render as solid shapes. Do not use them until they are re-exported.
- Patterns are decoration only: `alt=""`, never behind body text.
