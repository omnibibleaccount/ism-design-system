# ISM Email Types Playbook, Structure, Copy & Conversion Patterns

This playbook removes subjective guesswork. For each request, classify the email into one of the types below, then follow its proven structure, subject formulas, and CTA patterns. These patterns are engineered around the metrics that matter: **open rate (subject/preheader), click-through (single CTA, above the fold), response/conversion (specific first-person buttons), and deliverability (dark-on-light, live text, alt text).**

All types inherit every rule of `email-standard.md`. This file adds type-specific structure.

---

## How to Classify (decision logic)

Ask: *What is the ONE action this email should drive?* That answer sets the type.

| If the goal is... | Use type |
|---|---|
| Ask for a gift / financial support | **Appeal / Fundraising** |
| Say thank you after a gift or action | **Thank-You / Receipt** |
| Share a story of transformation | **Impact / Testimony** |
| Announce news, milestone, or launch | **Announcement / Milestone** |
| Recurring wins roundup | **Weekly Update / Celebration** |
| Invite to pray for a need | **Prayer Mobilization** |
| Welcome a new subscriber/partner | **Onboarding / Welcome** |
| Invite to an event, webinar, broadcast | **Event / Invitation** |
| Re-engage a lapsed partner | **Re-engagement / Winback** |
| Recruit volunteers / translators / advocates | **Recruitment / Volunteer** |

If a request blends two (e.g., impact story + gift ask), the **primary** CTA sets the type and the secondary goal becomes a secondary text link.

---

## Universal Anatomy (all types)

1. **Preheader** (35-90 chars), complements subject, never repeats it.
2. **Header band**, logo (light or dark variant per background). Flattened image only if dark.
3. **Hero**, one focal image (authentic, high-contrast) OR a bold Poppins headline.
4. **Greeting**, "Hi {FirstName}," / "Hi Friend," in **bold black**.
5. **Body**, Nunito 14-16px, dark-on-light, short paragraphs (2-3 sentences), mobile-first. Lead with the most compelling fact/number/story.
6. **Primary CTA button**, Horizon Blue, first-person, above the fold on mobile.
7. **Optional supporting block**, Scripture in Lora italic, secondary text link, or proof point.
8. **Sign-off**, bold black, three lines: "'til all have heard," / Troy Carl / President.
9. **Footer**, org name, tagline, 1-833-60-BIBLE (24253) | contact@ism.bible (once), address/unsubscribe (ESP route), ISM.Bible.

## Type Playbooks

### 1. Appeal / Fundraising
- **Structure:** Hook (specific need + number) → brief story/stakes → the ask → impact of the gift → primary CTA → Scripture anchor → PS with deadline/match.
- **Subject formulas:** "{Number} languages still waiting", "Will you help {specific outcome}?", "A door just opened in {place}".
- **Primary CTA:** "Yes, I'll Give to Reach {audience}" / "I'll Fund {N} Bibles".
- **Notes:** Make the gift's outcome concrete (X gift = Y Scripture access). One ask, one button.

### 2. Thank-You / Receipt
- **Structure:** Immediate gratitude → what their gift did (specific) → a glimpse of what's next → soft next step (not another ask) → Scripture.
- **Subject formulas:** "Thank you, {FirstName}", "Your gift is already at work".
- **Primary CTA:** "See the Impact of My Gift" / "Read {name}'s Story". Giving ask, if any, stays a secondary text link.

### 3. Impact / Testimony
- **Structure:** Open on the person/story → the barrier they faced → how Scripture access changed it → connect to the reader's role → CTA to go deeper or share.
- **Subject formulas:** "\u201c{short quote}\u201d", "How {Name} first heard the Word", "From {place}: a first Bible".
- **Primary CTA:** "Read the Full Story" / "Share This Story". Prioritize app-user testimonies when available.

### 4. Announcement / Milestone
- **Structure:** Lead with the news/number → why it matters to the mission → brief detail → CTA to engage → Scripture or vision line.
- **Subject formulas:** "{Number} languages now live", "We just launched {thing}", "A milestone worth celebrating".
- **Primary CTA:** "Explore the {thing}" / "See What's New".

### 5. Weekly Update / Celebration
- **Structure:** Warm open → 2-4 wins (scannable) → at least one positive testimony → a prayer point → CTA. (Aligns with the ISM weekly celebration email pattern; app-user testimonies first.)
- **Subject formulas:** "This week: {top win}", "{Number} lives, one week".
- **Primary CTA:** "Celebrate With Us" / "Read This Week's Story". Produce ISM and TTB versions when requested.
- **Notes:** Internal team updates from Troy's Gmail use the Gmail paste route; put audio samples behind Play links and keep the stat tiles and screenshots legible at 380px.

### 6. Prayer Mobilization
- **Structure:** The need (specific, human) → why now → how to pray (2-3 points) → commitment CTA → Scripture.
- **Subject formulas:** "Pray with us for {place}", "A team needs your prayers".
- **Primary CTA:** "Yes, I'll Pray for the Team".

### 7. Onboarding / Welcome
- **Structure:** Welcome + belonging → what to expect → one first action → Scripture of invitation. Keep it short.
- **Subject formulas:** "Welcome to the mission, {FirstName}", "You're in, here's your first step".
- **Primary CTA:** "Start Here" / "Download Dot Bible".

### 8. Event / Invitation
- **Structure:** What/when/where (scannable) → why attend → RSVP CTA → logistics → Scripture/vision.
- **Subject formulas:** "You're invited: {event}", "{Date}: join us for {event}".
- **Primary CTA:** "Save My Spot" / "Yes, I'll Join".
- **Notes:** Use ISM date/time style (Tuesday, March 9; 7–8:30 PM).

### 9. Re-engagement / Winback
- **Structure:** "We've missed you" → what's changed/what they missed → one compelling reason to return → low-friction CTA → Scripture of welcome-back.
- **Subject formulas:** "We've missed you, {FirstName}", "A lot has happened since we last talked".
- **Primary CTA:** "Show Me What's New".

### 10. Recruitment / Volunteer
- **Structure:** The opportunity + impact → who's needed → time/commitment clarity → CTA → Scripture of calling.
- **Subject formulas:** "Can you help translate {language}?", "We need {role}".
- **Primary CTA:** "Yes, I Want to Help".

## Subject Line Engineering (applies to all)

- Under ~45 characters, 6-10 words. Lead with specific news, a number, or a question.
- Prefer concrete over vague: "42 languages still waiting" beats "Help us reach the world."
- Preheader must add new information (a name, a number, a stakes line), never echo the subject.
- Recommend an A/B variant ONLY if the send list is 1,000+ recipients. When you do, provide two subject options and note the recommended primary.

## CTA Engineering (applies to all)

- Exactly one primary CTA per email. Repeat the same CTA lower in long emails.
- Button copy: first-person + specific verb + outcome. Never "Submit," "Click here," or "Learn more."
- Horizon Blue `#046DE3` button, white bold Poppins label, ~44px tall for tap targets.
- Any giving ask in a non-appeal email is a **secondary text link**, not a button.

## Personalization Tokens

- `{FirstName}` with `Friend` fallback (required).
- Optional, only if data supports it: `{City}`, `{Country}`, `{Language}`, `{LastGiftDate}`. Never render an empty token, always set a graceful fallback.
