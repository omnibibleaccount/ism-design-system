# Marketing email kit (superseded)

These files predate the ISM Email Design & Copy Standard (now v1.2). Do not build new emails from them.

Build every ISM and THRU the BIBLE email from the skill in [`skills/ism-emails/`](../../../skills/ism-emails/SKILL.md): its templates already contain the approved footers (dark for newsletters, light for everything else), signature and contact canon. See [`rules/email.md`](../../../rules/email.md) for the short form.

What changed and why these templates are no longer the reference:

| Here | Standard |
|---|---|
| 650px desktop and mobile files | One responsive 600px ESP template, or a 420px Gmail-paste template |
| Inter | Poppins headings, Nunito body, Lora quotes (with fallbacks) |
| Dark `#20242B` footer ("HTML-ISM-Dark-Footer") on every email | Newsletters only, standardised in `skills/ism-emails/assets/templates/newsletter-footer.html`; every other email uses the light footer |
| Gradient hero word | Colour is for action only: Horizon Blue on buttons and links |
| Cream quote band, abbreviated citation ("Rom. 10:17") | Lora italic Scripture, reference spelled out ("Romans 10:17") |

Kept for study only: module patterns (hero, stat rows, quote band) and the Outlook and dark-mode safety techniques.
